# ПЕРЕГОН

Анимационный мини-сериал: 5 серий по ~3 минуты (серия 1 после патча №1 — 2:18), 2.5D-вектор, всё нарисовано кодом на [Remotion](https://www.remotion.dev/) (React + TypeScript). Взрослый хоррор-детектив, 18+.

## Быстрый старт

```bash
npm install
npm run audio          # сгенерировать звук в public/audio (уже лежит в репозитории)
npm run studio         # Remotion Studio
```

Рендер:

```bash
npx remotion render Ep1 out/ep01.mp4 --codec h264 --crf 18      # … Ep2…Ep5
npx remotion render FullFilm out/peregon_full.mp4 --codec h264 --crf 18
./scripts/render_all.sh                                         # всё сразу
```

Рендер долгий (≈1–2 кадра/с на 4 ядрах), поэтому есть возобновляемый вариант — кусками по 900 кадров, которые переживают перезапуск машины:

```bash
python3 scripts/render_chunks.py render Ep3 Ep4 Ep5 ff --worker 0 --workers 2 &   # две очереди параллельно
python3 scripts/render_chunks.py render Ep3 Ep4 Ep5 ff --worker 1 --workers 2 &
python3 scripts/render_chunks.py assemble Ep3 Ep4 Ep5                            # покадрово точная склейка
python3 scripts/fullfilm_splice.py                                               # out/peregon_full.mp4
```

`fullfilm_splice.py` дорендеривает из композиции `FullFilm` только кадры, которые отличаются от отдельных серий (паузы вместо «РАНЕЕ», таймкоды без приписки, без карточек серий — ≈5300 кадров), и склеивает их с готовыми сериями покадрово. Честный рендер всех 27000 кадров — `npx remotion render FullFilm out/peregon_full.mp4 --codec h264 --crf 18` (или `FULL_RENDER=1 ./scripts/render_all.sh`); результат тот же.

В облачном контейнере SVG рисуется программно, и SwiftShader здесь в ~3 раза быстрее SwANGLE (`remotion.config.ts`).

Стоп-кадры для проверки (один бандл на все кадры, контактный лист):

```bash
node scripts/stills.mjs Ep3 /tmp/ep3 0,6,30,90,180,1:25,2:20
python3 scripts/contact.py /tmp/ep3/sheet.png /tmp/ep3/*.png
```

## Композиции

| ID | Длительность | Что это |
|---|---|---|
| `Ep1` … `Ep5` | 5400 кадров (3:00); Ep1 — 4137 (2:17.9) | Серии. Пропс `{standalone}`: `true` — с блоком «РАНЕЕ» и карточкой серии |

| `CharacterSheet` | still | Лист персонажей; пропс `section`: `all`, `heights`, `silhouettes`, `gleb`, `evolution`, `lights`, `blind`, `coat` |
| `Sandbox` | 300 кадров | Проверка параллакса, маски фонаря и декораций вагона |

## Устройство

```
src/
  config.ts              WIDTH/HEIGHT/FPS (вертикаль: поменять WIDTH и HEIGHT), летербокс 2.39:1
  theme/palette.ts       палитра
  lib/                   камера (2.5D, наезд/панорама/тряска), детерминированный шум, перспектива, шрифты, тайминг
  components/
    Stage25D.tsx         multiplane: слои с z, параллакс ∝ 1/z, туман по глубине (feColorMatrix)
    FX/                  зерно, виньетка, мерцание, ореолы, пыль, маска фонаря, сублиминальная вставка, трещины, летербокс
    Text/                монолог, реплики, таймкод, карандашные цифры, бланк «АКТ ОСМОТРА», хук, карточка
    Characters/          риг и все персонажи по PEREGON_characters.md (свет warm/emergency/flashlight/silhouette, LOD 0–2)
    Props/               вагон (сбоку и вдоль), туннель, гермозатвор, вентшахта, проход, кабина, город, дозиметр, блокнот, ампулы
  episodes/
    common/              «плёнка» серии, РАНЕЕ, пауза-переход, звук, крупные планы, общие декорации
    ep1 … ep5/           timing.ts (все длительности), scenes/*.tsx, index.tsx
scripts/gen_audio.py     синтез звука (numpy + scipy) + моменты щелчков дозиметра для синхронного индикатора
```

Правила, которые соблюдены во всём коде: анимация только от `useCurrentFrame()` (`interpolate` / `spring` / `Easing`), случайность только через `random(seed)`, шрифты (PT Serif, JetBrains Mono, Caveat — кириллица) через `@remotion/google-fonts` и `delayRender`, одно полноэкранное зерно на кадр, размытие — статичное на слой.

Длительность серии — сумма её сцен в `timing.ts` (`assertTiling` проверяет, что сцены идут без зазоров); `src/episodes/durations.ts` собирает длительности для `Root` и `FullFilm`. Под озвучку сцены можно удлинять — серия и фильм удлинятся сами. Скрипты рендера берут длительности из `EP_FRAMES` в `scripts/fullfilm_splice.py` — их нужно поправить вместе с `timing.ts`.

## Звук

Музыки нет. `scripts/gen_audio.py` синтезирует: стыки рельсов, гул туннеля 35–60 Гц, щелчки дозиметра (пуассоновский процесс: 0,5 / 2 / 8 / 40 / 200 в секунду), инфразвуковой удар с треском стекла, стук под полом, гудок электропоезда, сердцебиение, дыхание (в том числе «не с той стороны» — стерео), скрежет, радиошум оповещения и несколько служебных звуков. Индикатор на дозиметре мигает в те же моменты, что и щелчки в звуке (`src/audio/geigerTimes.json`).

## Озвучка (ElevenLabs)

Всё по `PEREGON_voice.md`, код в `voice/`. Ключ берётся только из переменной окружения `ELEVENLABS_API_KEY`: он не появляется ни в коде, ни в логах, ни в файлах.

```bash
pip install -r voice/requirements.txt
python3 voice/casting.py          # кандидаты на роли → voice/review/casting.html
# человек слушает, выбирает и сохраняет voice/voices.json
python3 voice/generate.py         # реплики → voice/raw/epN/<ID>.wav + .json (тайминг символов, seed, проверка)
python3 voice/process.py          # обработка → public/voice/epN/<ID>.wav + src/episodes/epN/voice.json
python3 voice/qa.py               # проверка → voice/review/index.html
python3 scripts/master_loudness.py out/ep01.mp4   # после рендера: −16 LUFS, пик ≤ −1 dBTP
```

- `voice/lines.py` — все реплики E1-01…E5-09 с тегами, окнами, обработкой и манерой; описания голосов для Voice Design.
- `voice/process.py` — базовая цепочка (срез < 70 Гц, де-эссер, компрессия 2:1, громкость по манере), пространства `CAR`/`CAR_DARK`/`TUNNEL`/`SHAFT`/`CAB` свёрткой с синтетическими импульсами, `INTERCOM`, `RADIO_INTERCOM` (выпадения не задевают ключевые слова), `STREET_PA`. `--selftest` прогоняет все цепочки на синтетическом сигнале без сети.
- Бесплатный тариф ElevenLabs: 10 000 символов в месяц, PCM только 24 кГц (передискретизируется в 44,1), через API доступны только стандартные голоса — ни Voice Design, ни голоса библиотеки. Поэтому `voice/voices.json` собран из стандартных голосов (Глеб — Brian, Нина — Sarah, Семён — Bill, Корнеев — Adam, Павел — Eric, диктор — Alice, Ольга — Lily, Ахмед — Harry, Пятнадцатый — Callum), они говорят по-русски через `eleven_v4`. С платным тарифом `voice/casting.py` подберёт русские голоса библиотеки, после этого — `generate.py --redo …`.
- `generate.py` перегенерирует только явный брак (не тот текст, произнесённый тег, клиппинг) и не тратит символы сверх остатка; остальные флаги — для прослушивания.
- Патч №1 (`PEREGON_patch_01.md`): `python3 voice/manifest.py` — инвентаризация (`voice/manifest.json`), `generate.py --new` — только отсутствующие реплики по приоритетам P1 → P2 → P3, не больше одного повтора, без перегенерации старых; `python3 voice/trim.py` — паузы внутри реплик длиннее 0,6 с сокращаются до 0,5 с (смысловые — до 0,9 с, E2-06 — 0,8 с), края — 40 мс, результат в `voice/trimmed` (из него берёт `process.py`). `python3 scripts/pace_check.py out/ep01.mp4 1` — участки длиннее 2,5 с без нового события (слово, звуковой всплеск, заметная смена в кадре).
- В сценах моменты событий берутся из голоса: `useWordFrame('E1-10', 'пятнадцать', запасной_кадр)` — кадр, на котором произносится слово (цифра пишется, свет мигает, план меняется ровно на нём); `ContractClause` — страница правил страхования с обведённым пунктом.
- Привязка к картинке: у реплики `scene` и `pos` — первое слово звучит через `pos` секунд от начала сцены из `timing.ts`; `at={слово: секунды}` вставляет паузу, чтобы слово попало на нужный кадр (цифра на стене, смена плана). Так привязана серия 1 (после патча №1 — без вставных пауз: картинка идёт за голосом); у серий 2–5 `voice.json` пока пустые — генерации лежат в `voice/raw`, привязка и подгонка сцен ещё не сделаны.
- В Remotion: `<Film voice={…}>` проигрывает реплики из `voice.json`; `Monologue`, `Subtitle` и `HookText` с пропсом `voice="E1-02"` печатают и показывают текст по таймингу произнесённых символов; зацикленный фон сам уходит на −5 дБ под голосом. Пока `voice.json` пустой, серии рендерятся как раньше.
